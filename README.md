# Flores ML - Clasificación de Flores

> Proyecto de Ciencia de Datos e Ingeniería de IA siguiendo la metodología SpecDD + TDD.

## Estructura del Proyecto
- `docs/`: Documentación técnica y de negocio.
- `src/`: Código fuente productivo (.py).
- `data/`: Almacenamiento de datos (Bronze, Silver, Gold).
- `models/`: Artefactos de modelos serializados.
- `notebooks/`: Investigación y experimentación.
- `tests/`: Suite de pruebas técnicas.
- `infra/`: Infraestructura como código y Docker.

## Guía de Inicio Rápido
1. Instalar dependencias: `pip install -r requirements.txt` (Próximamente)
2. Consultar el Backlog en `docs/governance/backlog.md`.
